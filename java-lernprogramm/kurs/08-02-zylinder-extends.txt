=== titel
Vererbung mit extends
=== erklaerung
„Zylinder sind Kreise mit einer Höhe“ (Skript S. 32). Mit `extends` **erbt** eine Klasse alle Eigenschaften und Methoden der Basisklasse und kann neue hinzufügen:

```java
class Verkehrsrad extends Fahrrad {
    boolean licht;              // neu
    public void einaus(boolean ea) { this.licht = ea; }   // neu
}
```

Der Konstruktor der Subklasse ruft mit `super(...)` den Konstruktor der Basisklasse auf. **`super(...)` muss die erste Zeile im Konstruktor sein** (Skript S. 34):

```java
Zylinder() {
    super();        // Kreis() – Radius 1
    this.h = 1.0;
}
```

In Java kann eine Klasse nur von **einer** Klasse erben (Skript S. 32).
=== aufgabe
Vervollständige die Klasse `Zylinder`:

1. `Zylinder()` – Radius 1 (über `super()`), Höhe 1
2. `Zylinder(double r, double h)` – Radius über `super(r)`, dazu die Höhe
3. `setH(double h)` – setzt die Höhe und gibt sie zurück (wie `setRad`)
4. `getH()`
=== vorlage
public class Main {
    public static void main(String[] args) {
        Zylinder z = new Zylinder(2, 5);
        System.out.println("Radius: " + z.getRad());   // geerbt!
        System.out.println("Höhe: " + z.getH());
    }
}

class Kreis {
    protected double r;

    Kreis() {
        this.r = 1.0;
    }

    Kreis(double r) {
        this.r = r;
    }

    double setRad(double r) {
        this.r = r;
        return r;
    }

    double getRad() {
        return r;
    }

    double flaeche() {
        return Math.PI * r * r;
    }

    double umfang() {
        return 2 * Math.PI * r;
    }
}
