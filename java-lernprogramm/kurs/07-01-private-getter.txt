=== titel
private und Getter
=== erklaerung
**Datenkapselung** heißt: Kein direkter Zugriff auf die Daten eines Objekts „von außen“. Objekte kommunizieren nur über **Methoden** (Skript S. 28).

In Java machst du Instanzvariablen dazu `private` und bietest **Getter** (zum Lesen) und **Setter** (zum Ändern) an (Skript S. 29):

```java
class Fahrrad3 {
    private String farbe;

    public String getFarbe() {
        return farbe;
    }

    public void setFarbe(String farbe) {
        this.farbe = farbe;
    }
}
```

`meinRad.farbe = "rot";` würde jetzt vom Compiler abgelehnt – nur noch `meinRad.setFarbe("rot");` ist erlaubt.

Ein **Konstruktor** ist eine besondere Methode mit dem Namen der Klasse und **ohne Rückgabetyp**. Er läuft bei `new` und setzt Startwerte (Skript S. 30):

```java
Fahrrad4() {
    this.eigentuemer = "Nobody";
}
```

=== loesung
public class Main {
    public static void main(String[] args) {
        KaderSpieler s = new KaderSpieler();
        System.out.println(s.getName() + " " + s.getNummer());
    }
}

class KaderSpieler {
    private String name;
    private int nummer;
    private int tore;

    KaderSpieler() {
        this.name = "Unbekannt";
        this.nummer = 0;
        this.tore = 0;
    }

    String getName() {
        return name;
    }

    int getNummer() {
        return nummer;
    }

    int getTore() {
        return tore;
    }
}
=== tipp
Im Konstruktor: `this.name = "Unbekannt";` usw.
=== tipp
Ein Getter gibt einfach den Wert zurück: `return name;`
