=== titel
Der Kopierkonstruktor
=== erklaerung
Im Skript (S. 30) hat `Fahrrad4` einen Konstruktor, der ein **anderes Fahrrad** als Vorlage bekommt:

```java
public Fahrrad4(Fahrrad4 f) {
    this(f.eigentuemer, f.farbe);   // ruft den Konstruktor (String, String) auf
    this.geschw = f.geschw;
}
```

- `this(...)` ruft einen **anderen Konstruktor derselben Klasse** auf. Das muss die **erste** Anweisung sein.
- Innerhalb der Klasse darfst du auch auf die `private`-Variablen eines **anderen** Objekts derselben Klasse zugreifen.

So entsteht ein **neues, unabhängiges** Objekt mit denselben Werten.
=== aufgabe
Schreibe den Kopierkonstruktor `KaderSpieler(KaderSpieler s)`. Er übernimmt Name, Nummer **und** Tore. Verwende `this(...)`.
=== vorlage
public class Main {
    public static void main(String[] args) {
        KaderSpieler original = new KaderSpieler("Seider", 53);
        original.torErzielen();
        KaderSpieler kopie = new KaderSpieler(original);
        System.out.println(kopie.getName() + " " + kopie.getTore());
    }
}

class KaderSpieler {
    private String name;
    private int nummer;
    private int tore;

    KaderSpieler(String name, int nummer) {
        this.name = name;
        this.nummer = nummer;
    }

    KaderSpieler(KaderSpieler s) {
        // Dein Code hier
    }

    void torErzielen() {
        tore++;
    }

    String getName() {
        return name;
    }

    int getNummer() {
        return nummer;
    }

    int getTore() {
        return tore;
    }
}

=== loesung
public class Main {
    public static void main(String[] args) {
        KaderSpieler original = new KaderSpieler("Seider", 53);
        original.torErzielen();
        KaderSpieler kopie = new KaderSpieler(original);
        System.out.println(kopie.getName() + " " + kopie.getTore());
    }
}

class KaderSpieler {
    private String name;
    private int nummer;
    private int tore;

    KaderSpieler(String name, int nummer) {
        this.name = name;
        this.nummer = nummer;
    }

    KaderSpieler(KaderSpieler s) {
        this(s.name, s.nummer);
        this.tore = s.tore;
    }

    void torErzielen() {
        tore++;
    }

    String getName() {
        return name;
    }

    int getNummer() {
        return nummer;
    }

    int getTore() {
        return tore;
    }
}
=== tipp
Erste Zeile: `this(s.name, s.nummer);`
=== tipp
Danach noch die Tore übernehmen: `this.tore = s.tore;`
