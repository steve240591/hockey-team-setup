=== titel
Dynamische Bindung
=== erklaerung
Eine Variable vom Typ der Basisklasse darf auf eine Instanz der Subklasse zeigen:

```java
Kreis k = new Zylinder(2, 5);   // Objekt vom Typ Kreis, Instanz von Zylinder
k.flaeche();                    // ruft flaeche() aus ZYLINDER auf!
```

Welche Methode läuft, wird erst **zur Laufzeit** anhand der tatsächlichen Instanz entschieden – das ist die **dynamische Bindung** (Skript S. 34/35).

Methoden, die es nur in der Subklasse gibt, erreichst du über eine **Typkonvertierung**. Mit `instanceof` prüfst du vorher, ob das sicher ist:

```java
if (k instanceof Zylinder) {
    double h = ((Zylinder) k).getH();
}
```
=== aufgabe
Das Array enthält Kreise **und** Zylinder.

1. `gesamtFlaeche(Kreis[] formen)` – Summe aller `flaeche()`-Werte
2. `summeHoehen(Kreis[] formen)` – Summe der Höhen aller Zylinder (normale Kreise ignorieren)
=== vorlage
public class Main {

    static double gesamtFlaeche(Kreis[] formen) {
        // Dein Code hier
        return 0;
    }

    static double summeHoehen(Kreis[] formen) {
        // Dein Code hier
        return 0;
    }

    public static void main(String[] args) {
        Kreis[] formen = {new Kreis(1), new Zylinder(1, 1), new Kreis(2), new Zylinder(1, 3)};
        System.out.println(gesamtFlaeche(formen));
        System.out.println(summeHoehen(formen));
    }
}

class Zylinder extends Kreis {
    protected double h;

    Zylinder(double r, double h) {
        super(r);
        this.h = h;
    }

    double getH() {
        return h;
    }

    @Override
    double flaeche() {
        return 2 * super.flaeche() + h * super.umfang();
    }
}

class Kreis {
    protected double r;

    Kreis() {
        this.r = 1.0;
    }

    Kreis(double r) {
        this.r = r;
    }

    double setRad(double r) {
        this.r = r;
        return r;
    }

    double getRad() {
        return r;
    }

    double flaeche() {
        return Math.PI * r * r;
    }

    double umfang() {
        return 2 * Math.PI * r;
    }
}

=== loesung
public class Main {

    static double gesamtFlaeche(Kreis[] formen) {
        double summe = 0;
        for (Kreis k : formen) {
            summe += k.flaeche();
        }
        return summe;
    }

    static double summeHoehen(Kreis[] formen) {
        double summe = 0;
        for (Kreis k : formen) {
            if (k instanceof Zylinder) {
                summe += ((Zylinder) k).getH();
            }
        }
        return summe;
    }

    public static void main(String[] args) {
        Kreis[] formen = {new Kreis(1), new Zylinder(1, 1), new Kreis(2), new Zylinder(1, 3)};
        System.out.println(gesamtFlaeche(formen));
        System.out.println(summeHoehen(formen));
    }
}
